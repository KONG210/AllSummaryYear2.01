## 1. หาขนาด Data Payload สูงสุดต่อ 1 packet

```text
Max Data = MTU − IP header (20 bytes)
ต้องหาร 8 ลงตัว → ถ้าไม่ลงตัว ให้ปัดลงเป็นเลขที่หาร 8 ลงตัวที่ใกล้สุด
Max Data ต่อ packet = floor((MTU − 20) / 8) × 8
```

**ตัวอย่าง** MTU = 1000 → 1000 − 20 = 980 → 980 / 8 = 122.5 ✗ → ปัดลง 122 → 122 × 8 = **976 bytes**

> ⚠️ ห้ามปัดขึ้น 123 × 8 = 984 เพราะ 984 + 20 = 1004 ซึ่งเกิน MTU

## 2. คำนวณการแบ่ง Fragment

**สูตรประจำชิ้น**
```text
Data ชิ้นนี้      = Max Data (ชิ้นสุดท้าย = ที่เหลือ)
ช่วง byte        = เริ่ม .. เริ่ม + Data − 1
Total Length     = Data + 20
MF flag          = 1 ทุกชิ้น ยกเว้นชิ้นสุดท้าย = 0
Fragment Offset  = byte เริ่มต้น / 8
จำนวน fragment   = ceil(Data ทั้งหมด / Max Data)
```

**ตัวอย่าง** Data payload = 3200 bytes, MTU = 1000 (Max Data = 976)

| ชิ้น | ข้อมูลที่เหลือก่อนหั่น | Data | ช่วง byte | Total Length | MF | Offset |
|---|---|---|---|---|---|---|
| 1 | 3200 | 976 | 0 – 975 | 996 | 1 | 0/8 = **0** |
| 2 | 2224 | 976 | 976 – 1951 | 996 | 1 | 976/8 = **122** |
| 3 | 1248 | 976 | 1952 – **2927** | 996 | 1 | 1952/8 = **244** |
| 4 | 272 | **272** | **2928** – 3199 | **292** | **0** | 2928/8 = **366** |

> ⚠️ **ในโน้ตเขียนผิด:** ชิ้นที่ 3 จบที่ **2927** (1952 + 976 − 1) ไม่ใช่ 2957 และชิ้นที่ 4 เริ่มที่ **2928** ไม่ใช่ 2958 · เช็กได้จาก offset: 366 × 8 = 2928 (ส่วน 2958 / 8 ไม่ลงตัว)

> ⭐ เช็กคำตอบเร็วๆ: **offset ต้องเพิ่มทีละ Max Data / 8 เท่ากันทุกชิ้น** (ตัวอย่างนี้เพิ่มทีละ 122) และ byte สุดท้ายของชิ้นสุดท้าย = Data ทั้งหมด − 1

> ⚠️ อ่านโจทย์ให้ดีว่าให้ **"data payload"** หรือ **"datagram ขนาด X (รวม header)"** · ถ้ารวม header ต้องลบ 20 ก่อนจึงจะได้ data จริง เช่น datagram 4000 → data 3980

## 3. Prefix (/CIDR) → Subnet Mask และจำนวน IP

```text
IP ทั้งหมด     = 2^(32 − prefix)
IP ที่แจกได้  = 2^(32 − prefix) − 2     (ตัด Network และ Broadcast)
```

| Prefix | Subnet Mask | IP ทั้งหมด | แจกได้ |
|---|---|---|---|
| /24 | 255.255.255.0 | 256 | 254 |
| /25 | 255.255.255.128 | 128 | 126 |
| /26 | 255.255.255.192 | 64 | 62 |
| /27 | 255.255.255.224 | 32 | 30 |
| /28 | 255.255.255.240 | 16 | 14 |
| /29 | 255.255.255.248 | 8 | 6 |
| /30 | 255.255.255.252 | 4 | 2 |

> ⭐ จำค่า octet สุดท้ายของ mask: **128, 192, 224, 240, 248, 252, 254, 255** (บวกค่า bit 128, 64, 32, 16, 8, 4, 2, 1 สะสมไปเรื่อยๆ)

## 4–5. หา Block Size และ Subnet Mask

**ตัวอย่าง** IP = 192.168.10.0/26
1. Block size = 2^(32 − 26) = 2^6 = **64**
2. Mask octet สุดท้าย = 256 − 64 = **192** → **255.255.255.192**

## 6. หาค่าต่างๆ ของวงแรก

นับวงแรกจาก 0 ถึง 63 (เพราะวงละ 64 IP)
- Network Address: **192.168.10.0**
- Usable IP Range: **192.168.10.1 – 192.168.10.62** (แจกได้ 62 เครื่อง)
- Broadcast Address: **192.168.10.63**

## 7. แบ่งช่วงการแจก IP ทุกวง

จำนวน subnet = 256 / block size = 256 / 64 = **4 subnets** (วงละ 64 IP)

| วงที่ | เริ่มที่ | Network | Usable Range | Broadcast |
|---|---|---|---|---|
| 1 | 0 | 192.168.10.0 | .1 – .62 | .63 |
| 2 | 64 | 192.168.10.64 | .65 – .126 | .127 |
| 3 | 128 | 192.168.10.128 | .129 – .190 | .191 |
| 4 | 192 | 192.168.10.192 | .193 – .254 | .255 |

> ⭐ Broadcast ของแต่ละวง = Network ของวงถัดไป − 1

## 8. IP นี้อยู่ในช่วง Block ไหน

**ตัวอย่าง** IP = 10.10.15.110/28 (ดูแค่ octet ท้าย .110)
1. Block size = 2^(32 − 28) = 2^4 = **16**
2. หาผลคูณของ 16 ที่ครอบ 110: 16 × 6 = 96 และ 16 × 7 = 112
3. ช่วงของวงนี้คือ **10.10.15.96 – 10.10.15.111**
   - Network **.96** · Usable **.97 – .110** · Broadcast **.111**

**สูตรลัด:** `network = floor(110 / 16) × 16 = 6 × 16 = 96` · `broadcast = network + block − 1 = 111`

## 9. VLSM (Variable Length Subnet Mask)

**ขั้นตอน**
1. **เรียงแผนกจากต้องการมากไปน้อย** (ห้ามข้าม ไม่งั้น network จะไม่หาร block ลงตัว)
2. ขนาดวง = 2^n ที่ ≥ (จำนวนเครื่อง + 2)
3. prefix = 32 − n · mask octet ท้าย = 256 − 2^n
4. วงแรกเริ่มที่ .0 แล้ววงถัดไปเริ่มที่ broadcast ของวงก่อน + 1

**ตัวอย่าง** ได้ 192.168.1.0/24 · Sales 100 เครื่อง, IT 50 เครื่อง

| แผนก | ต้องการ | +2 | ขนาดวง | Prefix | Mask | Network | Usable | Broadcast |
|---|---|---|---|---|---|---|---|---|
| Sales | 100 | 102 | 128 (2^7) | /25 | 255.255.255.128 | 192.168.1.0 | .1 – .126 | .127 |
| IT | 50 | 52 | 64 (2^6) | /26 | 255.255.255.192 | 192.168.1.128 | .129 – .190 | .191 |

- IT เริ่มต่อจาก Sales: 0 + 128 = **128** · broadcast = 128 + 64 − 1 = **191**

> ⚠️ +2 แล้วได้พอดี 2^n ก็ใช้ 2^n นั้นได้ เช่น 62 เครื่อง → 64 → /26 แต่ 63 เครื่อง → 65 → ต้องใช้ 128 (/25)

## 10. แนวข้อสอบจริง: VLSM + VLAN (10 คะแนน)

> 📌 ข้อสอบตัวอย่างที่ได้มา หน้าตาแบบนี้ ข้อละ 2 คะแนน (ตารางแถวละ 2 + ข้อ 2 + ข้อ 3 = 10)

**โจทย์:** โรงพยาบาลได้วง **10.20.30.0/24** ต้องแบ่งให้ 3 หน่วยงานแบบ VLSM ให้ประหยัดที่สุด

| VLAN | หน่วยงาน | ต้องการ | +2 | ขนาดวง |
|---|---|---|---|---|
| 10 | Nurse | 100 | 102 | 2^7 = **128** |
| 20 | Doctor | 30 | 32 | 2^5 = **32** (พอดี) |
| 30 | Pharmacy | 6 | 8 | 2^3 = **8** (พอดี) |

**ข้อ 1:** หา Prefix, Subnet Mask, Network, Usable Range, Broadcast และให้ **IP ใช้งานได้ตัวแรกเป็น Default Gateway**

| VLAN | Prefix | Subnet Mask | Network | Usable Range | Broadcast | Gateway |
|---|---|---|---|---|---|---|
| 10 | /25 | 255.255.255.128 | 10.20.30.0 | 10.20.30.1 – 10.20.30.126 | 10.20.30.127 | 10.20.30.1 |
| 20 | /27 | 255.255.255.224 | 10.20.30.128 | 10.20.30.129 – 10.20.30.158 | 10.20.30.159 | 10.20.30.129 |
| 30 | /29 | 255.255.255.248 | 10.20.30.160 | 10.20.30.161 – 10.20.30.166 | 10.20.30.167 | 10.20.30.161 |

- prefix = 32 − n: 2^7 → /25 · 2^5 → /27 · 2^3 → /29
- วงถัดไปเริ่มต่อจาก broadcast: 0 → 128 (0+128) → 160 (128+32)
- **Gateway = First usable = Network + 1**

**ข้อ 2:** เครื่องที่ใช้ IP 10.20.30.140 อยู่ VLAN ไหน
→ .140 อยู่ในช่วง .128 – .159 → **VLAN 20**

**ข้อ 3:** แบ่งครบ 3 VLAN แล้ว เหลือ IP ช่วงไหนว่าง
→ ใช้ไปถึง .167 → ว่าง **10.20.30.168 – 10.20.30.255** (88 เบอร์)

> ⚠️ ระวัง: Doctor 30 เครื่อง + 2 = 32 พอดี ใช้ /27 ได้ (แจกได้ 30 พอดี) ไม่ต้องขยับไป /26 · แต่ถ้าต้องการ 31 เครื่อง → 33 → ต้องใช้ 64 (/26)

> ⭐ ยังไม่คล่อง: **[สอนทำทีละขั้น](#learn)** พาทำทีละช่อง บอกเหตุผลทุกขั้น พิมพ์ตอบแล้วตรวจทันที

> ⭐ อยากได้กระดาษแบบนี้มาทำ: **[ข้อสอบเสมือนจริง](#paper)** สุ่มชุดใหม่ได้ มีเฉลย และพิมพ์ได้

> ⭐ ฝึกแนวนี้ได้ที่ **[หน้าฝึกคำนวณ](#calc)** เลือกแท็บ **VLSM + VLAN (แนวข้อสอบ)** โจทย์สุ่มหน้าตาเหมือนข้อสอบ มีทั้ง gateway, ถาม IP อยู่ VLAN ไหน และช่วงที่ว่าง

## จุดเน้นสำหรับสอบ
- 🔥 Max data ต้อง **หาร 8 ลงตัว ปัดลงเสมอ**
- 🔥 offset = byte เริ่มต้น / 8 · MF = 0 เฉพาะชิ้นสุดท้าย · total length = data + 20
- 🔥 block = 2^(32 − prefix) · mask = 256 − block · network หาร block ลงตัว
- 🔥 broadcast = network + block − 1 · usable = network + 1 ถึง broadcast − 1
- 🔥 VLSM เรียงใหญ่ไปเล็ก และอย่าลืม +2 · **Gateway = IP ใช้งานได้ตัวแรก**
- 🔥 แนวข้อสอบ: ตาราง VLAN + หา IP อยู่ VLAN ไหน + ช่วง IP ที่ว่าง
- ⭐ ฝึกมือให้คล่องที่ **[หน้าฝึกคำนวณ](#calc)** อย่างน้อยแบบละ 3–5 ข้อ
