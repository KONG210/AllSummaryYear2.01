# Lab 8 · AI-assisted Programming Workshop

## ภาพรวม
**เป้าหมาย:** เรียนรู้และฝึกพัฒนาเว็บแอปโดยใช้เครื่องมือ AI เป็นผู้ช่วย (**vibe coding**) — เชื่อมกับหัวข้อ "Emerging Development Approaches" ใน ITDS261 L10 (no-code, low-code, vibe coding)

> 🔗 ใจความ: prompt เดียวกันในเครื่องมือต่างกันให้ผลต่างกัน → ปรับระบบทีละ prompt → เพิ่มฟีเจอร์เอง → สะท้อนว่า prompt ที่ดีเป็นแบบไหน และ **ไว้ใจ AI โดยไม่ตรวจไม่ได้**

## ส่วนที่ 1: เครื่องมือ
| เครื่องมือ | วิธีเริ่ม |
|---|---|
| **Canva Code** | canva.com/ai-code-generator → "Code for me" → สมัคร (ใช้ Canva Education ด้วยอีเมลมหาวิทยาลัยได้ premium ฟรี) → "Canva AI" → ใส่ prompt ใน "Describe your ideas" |

ทดลอง **prompt เดียวกันทั้งสองเครื่องมือ** แล้วเปรียบเทียบ

## ส่วนที่ 2: สร้างโปรเจกต์ MUICT Club Registration System
**Prompt หลัก:** ระบบสมัครชมรม ICT ที่ (a) ดูรายการชมรม (AI, Dev, IoT, Cyber, Badminton, Table Tennis, Japanese Society, Board Game, Media and Entertainment, Speakers) (b) ดูข้อมูลแต่ละชมรม (c) สมัครชมรม (d) ดูชมรมที่สมัครแล้ว

**ปรับปรุงทีละ prompt (incremental prompting)**
1. ห้ามสมัครชมรมเดิมซ้ำ และแต่ละชมรมมีจำนวนสมาชิกสูงสุด
2. เพิ่มช่องค้นหาและกรองตามหมวดหมู่
3. เพิ่มหน้าผู้ดูแล (admin) จัดการชมรมและดูรายชื่อผู้สมัคร

## ส่วนที่ 3: เพิ่มฟีเจอร์เอง 2 ฟีเจอร์
ขั้นตอนต่อฟีเจอร์: **ระบุฟีเจอร์ → เขียน prompt → ใส่ในเครื่องมือ → ถ้าไม่ได้ผลให้เขียน prompt แก้ → บันทึกผล**

**งานของคุณ**
| ฟีเจอร์ | Prompt สำคัญ | ผล |
|---|---|---|
| **Favorites** | ปุ่มดาวบนการ์ดทุกใบ, แท็บ Favorites พร้อมตัวเลข, บันทึกด้วย **localStorage**, คงสีและรูปแบบเดิม, ปุ่มดาวใช้คีย์บอร์ดได้ | ได้ตามต้องการรอบแรก |
| **Export CSV** | ปุ่มในหน้า admin, คอลัมน์ชื่อชมรม/ชื่อ/รหัส/อีเมล/ข้อความ/วันเวลา, **UTF-8 + BOM** ให้ Excel อ่านไทยได้, escape comma/quote, กันข้อความขึ้นต้น `= + - @` ถูกตีความเป็นสูตร (**CSV injection**) | รอบแรกไม่มี BOM และขึ้นบรรทัดผิด → prompt ใหม่ระบุ BOM จริง + **CRLF** + ทดสอบด้วยข้อมูลไทย/comma/quote/สูตร → ได้ผล |

> ⭐ บทเรียนจากฟีเจอร์ CSV: prompt ต้อง **ระบุรายละเอียดทางเทคนิค** (encoding, line ending, escaping, security) และต้อง **ทดสอบผลจริง** เพราะ AI บอกว่าทำแล้วแต่ผลอาจยังไม่ถูก

## ส่วนที่ 4: Reflection (ประเด็นที่ควรตอบได้)
1. **Canva Code vs Lovable** ต่างกัน (คำตอบของคุณ): Canva ออกแบบสวยกว่า (ฟอร์ม ฟอนต์ สี) และทำตาม prompt ได้ตรงกว่า, Lovable ต้อง prompt 2 รอบ
2. **Prompt สั้นแล้วปรับทีละขั้น:** ข้อดี = หาข้อผิดพลาดง่าย แก้เร็ว · ข้อเสีย = ต้องแก้หลายรอบ อาจเสียเวลา
3. **เมื่อ AI ทำไม่ตรงที่คาด:** ต้องปรับ prompt ต่อไปเรื่อย ๆ
4. **Prompt ที่ดี:** ชัดเจน, แบ่งเป็นขั้น (step 1, 2, 3), มีลำดับการทำงาน, ไม่กำกวม, ระบุข้อจำกัด/รูปแบบผลลัพธ์
5. **ไว้ใจ AI โดยไม่ตรวจได้ไหม:** **ไม่ได้** — AI ทำตามคำสั่งแต่ไม่คิดเรื่องช่องโหว่/ความเสี่ยงเอง (เช่น ข้อมูลรั่ว, CSV injection) ต้อง review และ test เสมอ

## เชื่อมกับทฤษฎี (ITDS261 L10)
- Vibe coding: ข้อดี = barrier ต่ำ, interactive, เร็ว · ข้อจำกัด = logic ซับซ้อนยาก, **ผูกกับ platform**, **พึ่ง AI มากเกินไป**
- ผลจาก AI ยังต้องผ่าน **code review** และ **testing** เหมือนโค้ดที่คนเขียน
