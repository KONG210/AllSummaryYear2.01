# Lab 11 · เช็กลิสต์ก่อนสอบ

> 📌 PT 10.3.5 · R1: G0/0 = 192.168.10.1 · G0/1 = 192.168.11.1 · S1 = .10.2 · S2 = .11.2 · PC1/2 = .10.10/.10.11 · PC3/4 = .11.10/.11.11 (ทั้งหมด /24)

- host ต้องมี **IP + mask + default gateway** · gateway = router interface ใน LAN เดียวกัน
- วิธีแก้ 5 ขั้น: ตรวจเอกสาร/หาจุด → หาวิธี → แก้ → ทดสอบ → จดบันทึก · **local ก่อน remote** · **แก้ทีละอย่าง**

| ปัญหา | อาการ | แก้ |
|---|---|---|
| PC1 IP นอกวง | ping PC2 ไม่ได้ | 192.168.10.10/24 gw 192.168.10.1 |
| S2 ไม่มี IP | ping S2 ไม่ได้เลย | `int vlan 1` → `ip address 192.168.11.2 255.255.255.0` → `no shut` + gw .11.1 |
| PC4 gateway ผิด | วงอื่นหา PC4 ไม่เจอ | gw = 192.168.11.1 |
| S1 ไม่มี gateway | วงอื่นหา S1 ไม่เจอ | `ip default-gateway 192.168.10.1` |

⭐ IP ผิดวง → ในวงไม่ผ่าน · gateway ผิด → ในวงผ่าน ข้ามวงไม่ผ่าน · ตรวจ: `ipconfig`, `show running-config`, `show ip interface brief`
