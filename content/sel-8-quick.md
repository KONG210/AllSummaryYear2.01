# Lab 8 · สรุปก่อนสอบ

- เครื่องมือ: **Canva Code**, **Lovable** — prompt เดียวกันได้ผลต่างกัน
- โปรเจกต์: MUICT Club Registration (ดูรายการ, ดูข้อมูล, สมัคร, ดูที่สมัคร) → ปรับทีละ prompt: ห้ามสมัครซ้ำ + จำกัดสมาชิก · ค้นหา + กรองหมวด · หน้า admin
- เพิ่มฟีเจอร์: ระบุ → เขียน prompt → ลอง → ปรับ prompt → บันทึก
- ฟีเจอร์ของคุณ: **Favorites** (ดาว + แท็บ + localStorage) · **Export CSV** (UTF-8 BOM, CRLF, escape, กัน CSV injection `= + - @`)
- **Prompt ที่ดี:** ชัด, เป็นขั้นตอน, มีลำดับ, ไม่กำกวม, ระบุรายละเอียดเทคนิคและข้อจำกัด
- Prompt สั้นทีละขั้น: แก้ง่าย หาจุดผิดง่าย แต่ใช้หลายรอบ
- **ไว้ใจ AI โดยไม่ตรวจไม่ได้**: AI ไม่คิดเรื่องความปลอดภัย/ความเสี่ยงเอง ต้อง review + test
- Vibe coding (L10): barrier ต่ำ, เร็ว · แต่ logic ซับซ้อนยาก, ผูก platform, พึ่ง AI เกิน
